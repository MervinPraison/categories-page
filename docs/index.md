# Categories Page

Display all WordPress categories in a sortable table.

```mermaid
graph LR
    A[📂 Categories] --> B[🔌 Plugin]
    B --> C[📊 Sortable Table]
    
    style A fill:#22C55E,stroke:#7C90A0,color:#fff
    style B fill:#6366F1,stroke:#7C90A0,color:#fff
    style C fill:#F59E0B,stroke:#7C90A0,color:#fff
```

## Quick Start

1. **Install** → Upload plugin
2. **Add** → Use `[get_categories]` shortcode
3. **Done!** 🎉

## Features

| Feature | Description |
|---------|-------------|
| 📊 Sortable Table | Click headers to sort |
| 📄 Pagination | Large category lists |
| 🎨 Customizable | CSS styling |
